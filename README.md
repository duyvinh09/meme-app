# 📸 Meme — Gen Z Expense Tracker & Daily Spending Moments

Meme is a modern expense tracking mobile app designed for Gen Z users.  
Instead of only recording numbers, Meme helps users save the **moments behind every spending decision** through photos, emotions, and memories.

> “Every expense tells a story.”

---

# ✨ Features

## 💰 Smart Expense Tracking
- Add income and expenses quickly
- Categorize transactions easily
- View daily, weekly, and monthly spending summaries
- Beautiful and intuitive UI designed for young users

## 📷 Spending Moments
- Capture photos for transactions
- Save memories behind purchases
- Create a visual financial diary

## 📊 Financial Insights
- Daily spending overview
- Income vs expense statistics
- Helpful spending summaries
- Easy-to-read charts and analytics

## ☁️ Cloud Sync
- Firebase Authentication
- Cloud Firestore database
- Secure user data storage
- Real-time sync across devices

## 🎨 Modern UI/UX
- Soft gradients and Gen Z-inspired design
- Smooth animations
- Clean and minimal experience
- Responsive mobile layout

# 🎯 Project Goal

Meme was created to make personal finance less boring and more emotional for young users.

Traditional expense tracker apps focus only on numbers.  
Meme combines:
- money management
- memories
- emotions
- lifestyle moments

into one experience.
